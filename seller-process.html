희망배송일 그룹을 생성하고 상품에 매핑하여, 사용자가 주문 시 선택한 희망배송일에 따라 발주가 보류·진행되는 전체 흐름을 보여주는 화면입니다.

주요 기능

  • 관련 Shop/어드민 화면 목록 확인
  • 희망 배송일 유형(고정 날짜 / 주문일 기준) 설정 UI 확인
